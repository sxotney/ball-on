# A curated, human-Reviewed Question Bank instead of AI-generated questions

Questions are drafted from the Rulebook (by Claude), then checked by Carl or Rani before shipping. The app never generates questions at runtime. A confidently wrong ruling would teach the Learner a wrong rule just before an assessed match, so correctness matters more than variety. The Learner can Flag any Question for re-review.

## Considered Options

- AI-generated questions at runtime: endless variety, but no human check and needs network and an API key.
- Learner-authored questions: good for learning, but it puts the work on Rani and gives no coverage guarantee.

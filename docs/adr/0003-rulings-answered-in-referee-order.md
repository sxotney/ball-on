# Scenarios are answered as a structured Ruling, not multiple choice

The Learner answers a Scenario in referee order: the Call, then the Penalty Points, then the Options for the Incoming Player, then the cue-ball state. Each part is marked separately. This mirrors her thinking at the table and shows exactly which part she got wrong (e.g. "right call, wrong penalty value"). Multiple choice lets her spot the answer instead of working it out. Every Scenario therefore has to encode a full Ruling, not just one correct option. That makes Questions more expensive to author and review, which we accept.

Marking is strict: a Ruling counts as correct for spaced repetition only if every part is right. Each part is still shown marked separately. Partial scores and self-marking were rejected because a partly right ruling at the table is still a wrong ruling.
